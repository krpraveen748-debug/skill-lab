# skill-lab

## Overview
**skill-lab** is a practical programming and development repository containing lab exercises, foundational scripts, and hands-on coding experiments. It serves as a structured workspace for practicing core programming concepts, version control workflows, and problem-solving exercises.

---

## Objectives
- Practice core programming fundamentals and hands-on lab tasks.
- Maintain a clean, version-controlled history of lab exercises using Git and GitHub.
- Build modular, readable code snippets for quick reference and revision.

---

## Repository Structure
```text
skill-lab/
├── simple                  # Introductory lab exercise / practice file
└── README.md               # Repository overview and usage instructions
```

---

## Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com
cd skill-lab
```

### 2. Inspect or Run Exercises
View the contents of the lab files directly in your terminal or editor:
```bash
cat simple
```

---

## Workflow for Adding New Lab Programs
Whenever you complete a new lab exercise, save it inside this folder and push it to GitHub:
```bash
git add .
git commit -m "Add new lab exercise"
git push
```
